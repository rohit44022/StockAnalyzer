Key terms for options beginners
  • BSM (Black-Scholes-Merton) — Mathematical model to calculate fair option premium from spot price, strike, time to expiry, interest rate, and implied volatility
  • Delta (Δ) — How much option price changes per ₹1 move in the underlying. Delta 0.5 = option gains ₹0.50 if NIFTY rises ₹1
  • Gamma (Γ) — How fast Delta itself changes. High gamma near strikes = Delta can flip quickly
  • Theta (Θ) — Daily time decay. Options lose value every day. Sellers earn theta, buyers pay it. Accelerates near expiry
  • Vega (ν) — Sensitivity to implied volatility changes. Rising IV inflates premiums; falling IV deflates them
  • DTE (Days To Expiry) — Calendar days until the option contract expires. Low DTE = high theta decay + pin risk
  • IV (Implied Volatility) — Market's expectation of future price swings, embedded in option prices. Higher IV = more expensive options
  • WFA (Walk-Forward Analysis) — Backtest method that trains on past data and tests on unseen future data, preventing curve-fitting
  • Profit Factor — Total winning ₹ ÷ Total losing ₹. Above 1.0 = net profitable. Above 1.5 = healthy edge
  • Return Efficiency — Actual return ÷ WFA expected return. 70-130% = strategy performing as expected. Below 70% = underperforming

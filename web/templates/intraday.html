Intraday Auto-Trading System — Setup Guide

Prerequisites

  • Dhan account with Data API subscription (₹499/mo) — api.dhan.co
  • Funds deposited in your Dhan account (no leverage used — system trades only with available cash)
  • Access Token — generate daily from Dhan API portal → copy into .env file

Configure .env

DHAN_CLIENT_ID=your_client_id
DHAN_ACCESS_TOKEN=your_daily_token

Token expires daily. Update it each morning before trading.

Start the Auto-Trader

Open a terminal and run one of:

# Paper mode (simulated, no real money) — test first!
.venv/bin/python -m intraday.trader

# Live mode (real orders with real money)
.venv/bin/python -m intraday.trader --live

# With custom capital for paper testing
.venv/bin/python -m intraday.trader --capital 200000

# With a custom watchlist
.venv/bin/python -m intraday.trader --live --watchlist RELIANCE SBIN TCS HDFCBANK

Leave this terminal running all day. The daemon sleeps outside market hours automatically.

Enable Trading

Flip the Auto-Trader toggle to ON on this page (above). Trading is OFF by default every day — you must explicitly enable it.

The toggle communicates with the running daemon via a state file. No daemon running = toggle does nothing.

What Happens When ON

9:15–9:30Market opens. System waits for opening range (first 30 min) to form.
9:30–14:45Scans watchlist every 15 min. Places MARKET orders for top signals. Each entry gets an automatic SL-M (Stop Loss Market) order.
14:45No new entries. Existing positions monitored.
15:15Hard exit — all open positions closed at market. Toggle auto-resets to OFF.

How Signals Work

Built on the Brooks Price Action engine running on 5-min candles:

  • SHORT_FIRST — Sell at resistance, cover at support (bearish setups)
  • LONG_FIRST — Buy at support, sell into resistance (bullish reversals)

Each signal includes: time-of-day quality (PRIME/OK/LUNCH/LATE), gap detection (GAP_UP/GAP_DOWN/FLAT), opening range breakout (ORB), and ATR-calibrated stop/targets.

How the Intraday Scanner works

  • Universe: Bearish stocks from daily Brooks engine (AI=SHORT, regime=BEAR/CHOPPY), or your custom watchlist
  • Analysis: Brooks PA engine on today's 5-min candles (isolated — no cross-day contamination)
  • SHORT_FIRST: Sell at resistance/EMA when 5-min shows SELL signal, cover at support — trend-following in bear market
  • LONG_FIRST: Buy at support when 5-min shows BUY signal, sell into resistance — counter-trend scalp in bear market
  • Opening Range: First 30 min (6 bars) establish the range. Breakouts get a confidence boost (Brooks Ch.8/12)
  • Gap Detection: Gap-up/gap-down identified from prior close — affects setup context
  • Time-of-Day: PRIME (9:15-10:30, +5 conf), OK (10:30-12:00/1:00-2:30), LUNCH (-15 conf), LATE (-10), no entries after 2:45 PM
  • Stops: ATR-based on today's 5-min bars (1.5× intraday ATR), not hardcoded percentage. Max 2.5%
  • Hard exit: All positions must close by 3:15 PM IST. No new entries after 2:45 PM
  • Data: Dhan API (primary, ₹499/mo) with yfinance fallback
